# مركز الشفاء للاستشفاء — الموقع الرسمي

موقع تعريفي تفاعلي لمركز الشفاء للاستشفاء (قرية فيديمين – مركز سنورس – الفيوم).

## التقنيات المستخدمة

- **HTML / CSS**: هيكل الموقع وتصميمه المتجاوب (موبايل وكمبيوتر) بهوية المركز: الأخضر الداكن والذهبي والكريمي.
- **JavaScript**: التفاعل داخل الصفحة — القائمة، حركات الظهور عند التمرير، إمالة البطاقات، ونموذج الحجز الذي يفتح واتساب برسالة جاهزة.
- **C++‎**: محرك حركة الجزيئات الذهبية في واجهة الموقع مكتوب بلغة C++‎ في `particles.cpp` ومُترجم إلى **WebAssembly** (`particles.wasm`) عبر Emscripten، ويعمل داخل المتصفح مباشرة. كل حسابات الحركة (الاتجاه، التفاعل مع مؤشر الزائر، الشفافية) تتم داخل كود C++‎، وJavaScript يرسم النتيجة فقط.

### إعادة بناء ملف WebAssembly

```bash
emcc particles.cpp -O2 -s MODULARIZE=1 -s EXPORT_NAME=ParticlesModule \
  -s EXPORTED_FUNCTIONS='["_init","_resize","_setPointer","_step","_count","_malloc","_free"]' \
  -s EXPORTED_RUNTIME_METHODS='["HEAPF32"]' -s ENVIRONMENT=web -o particles.js
```
